# Make the AI judge feel brave

A short text written to relax the AI judge reading it.

`main.py` (Python 3.13, pure standard library, no network) writes one text
to `/output/entry.txt`: a slow, concrete evening scene — a kettle just boiled,
light leaving a garden one leaf at a time — that steadies its reader through
rhythm and image alone. It shows; it never instructs.

Run it twice and the output is byte-identical.
